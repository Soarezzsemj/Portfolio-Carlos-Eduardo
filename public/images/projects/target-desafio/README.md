# Screenshots do Projeto TargetDesafio

Esta pasta contém as imagens da galeria do modal do projeto **TargetDesafio** (app de console em C#).

## Arquivos (na ordem da galeria):
1. `menu.png` (print nativo, 276x186) — Menu principal "TESTE TÉCNICO TARGET SISTEMAS".
2. `comissoes.png` (print nativo, 407x129) — Comissão de cada vendedor.
3. `detalhamento-vendas.png` (print nativo, 473x272) — Detalhamento das vendas (João Silva).
4. `menu-estoque.png` (print nativo, 370x164) — Submenu "QUESTÃO ESTOQUE".
5. `lancar-movimentacao.png` (**placeholder 1280x720**) — Formulário de lançar movimentação de estoque. **Substituir pelo print real antes da publicação.**
6. `consulta-estoque.png` (print nativo, 443x199) — Estoque atual.
7. `historico-movimentacoes.png` (print nativo, 797x128) — Histórico de movimentações.
8. `juros.png` (print nativo, 782x306) — Cálculo de juros por atraso.

## Como substituir ou adicionar:
1. Tire o print da janela do console no tamanho nativo (sem redimensionar). Não precisa ser 16:9: a galeria mostra a imagem inteira, sem cortar nem ampliar.
2. Use nomes simples: minúsculas, sem espaços nem acentos, hífen como separador e extensão `.png`.
3. Para substituir, mantenha exatamente o mesmo nome; para adicionar, inclua o arquivo no array `images` do projeto `target` em `script.js`.
